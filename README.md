# AI非正常人类情报站社区网站

在清迈，一起聊AI、分享真实经历、认识有趣的人。

**AI Unconventional Minds Station** — Meet in Chiang Mai to talk AI, share real experiences, and meet curious people.

This repository contains the source migration and community website MVP. It is free and open to people curious about AI; no technical background or commercial goal is required.

## Local development

Use Node.js 22+ and npm. After reviewing dependencies, run:

```sh
npm install
npm run dev
```

The app uses React, TypeScript, TanStack Start, and Tailwind CSS. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) and [docs/SOURCE_MIGRATION_AUDIT.md](docs/SOURCE_MIGRATION_AUDIT.md) for migration status and backend constraints.
